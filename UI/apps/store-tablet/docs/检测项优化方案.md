# 质检工具检测项优化方案（通俗版）

> 目的：让每个检测项**只在一个地方、用一种方式判一次**，别再重复点选。
> 核心原则一句话：**机器能自动测的、照片能看出来的，都不让店员手点；只有机器和 AI 都测不出来的，才让店员点，而且只点一次。**

## 判定方式说明

| 方式 | 谁在判 | 店员要不要动手 |
|------|--------|---------------|
| 自动（USB） | 插线直接读手机信息 | 不用，插上线就行 |
| 自动（H5） | 手机浏览器打开检测页自己测 | 不用，最多引导用户操作 |
| 自动（ADB） | 电脑指令模拟按键 | 不用 |
| AI 识别 | 系统看拍好的照片自动勾 | 只确认/纠正，不用一个个点 |
| 店员目视 | 店员眼睛看 | 要，但只打「具体缺陷分级」 |
| 店员点选 | 只有人知道的（维修史/配件） | 要 |

---

## 完整检测流程

### 第 1 步：外观拒收判断（拍照前，扫一眼）

**这一步是「门槛」，不是打分。** 明显不能收的机子直接拒收，省得后面白拍一堆照。

| 看什么 | 怎么看 | 方式 |
|--------|--------|------|
| 屏幕碎得厉害吗 | 明显碎裂 | 店员目视 |
| 机身弯得厉害吗 | 明显变形 | 店员目视 |
| 进水严重吗 | 明显进水/主板腐蚀 | 店员目视 |

> 严重 → 拒收；不严重 → 继续往下走。

### 第 2 步：准入检查（连上设备 + 问用户）

**查「这台机子能不能收」。** 大部分系统自动查，只有一两项要人看。

| 检查项 | 查什么 | 方式 |
|--------|--------|------|
| IMEI 黑名单 | 是不是报失/失窃机 | 自动（联网查） |
| 账户锁 | 苹果 ID / 谷歌账号退没退 | 自动（读设备） |
| 无法开机 | 能不能开机 | 自动（读设备） |
| 分期没还清 | 还在分期吗 | 自动（联网查） |
| 运营商锁 | 锁网了吗 | 自动（联网查） |
| 进水 | 有没有进水痕迹 | 自动（看 LCI 进水标）+ 店员确认 |
| 电池鼓包 | 后盖鼓不鼓 | 店员目视（**和后面外观步骤合并，只判一次**） |

### 第 3 步：硬件检测（USB + 手机浏览器 H5）

**测「能不能用」，几乎全是机器自动，店员不用点。**

| 部件 | 测什么 | 方式 |
|------|--------|------|
| 品牌 / 型号 / 颜色 | 什么机型、什么颜色 | 自动（USB 读） |
| IMEI | 序列号 | 自动（USB 读） |
| 电池健康度 | 剩百分之几 | 自动（USB 读） |
| 屏幕显示 | 纯色画面下有没有缺陷 | **H5 放画面 + 店员目视打分**（见下方说明） |
| 屏幕触控 | 滑涂灵不灵 | 自动（H5） |
| 传感器 | 转动机身灵不灵 | 自动（H5） |
| 摄像头 | 前后摄能不能用 | 自动（H5） |
| 扬声器 / 麦克风 | 声音、录音正常吗 | 自动（H5） |
| 按键 | 音量、电源键有反应吗 | 自动（ADB） |

> **关于「屏幕显示」的特别说明**：H5 只能帮你「把屏幕变成纯色画面」，但「烧屏 / 坏点 / 偏色 / 漏液」具体是哪种、多严重，机器和照片都判不了，得店员眼睛看。所以这一项是「**H5 放画面 + 店员目视打分**」，和「屏幕显示」放在同一步里完成，**不再另外开一张重复的卡片**。触控不用店员点——H5 滑涂自动测，测出问题自动记。

### 第 4 步：拍照 + 视频（采集，不判定）

拍 10 张照片 + 1 段旋转视频，供后面 AI 看。这步不做任何判定。

### 第 5 步：外观检测（AI 看照片自动勾）

**测「外观磨损」，AI 自动勾，店员只确认 / 纠正。**

| 部位 | 看什么 | 方式 |
|------|--------|------|
| 屏幕玻璃 | 划痕、裂纹、脱层 | AI 识别（店员确认） |
| 边框 | 掉漆、凹痕、划痕 | AI 识别（店员确认） |
| 后盖 | 划痕、裂纹、磨损 | AI 识别（店员确认） |
| 充电口 / 接口 | 物理状态、腐蚀 | AI 识别（店员确认） |
| 按键 | 音量 / 电源键物理状态 | AI 识别（店员确认） |
| 电池鼓包 | 后盖鼓不鼓 | AI 识别 + **和第 2 步联动，判一次** |

### 第 6 步：维修 / 配件（只能问用户）

**只有人知道的，问用户 + 店员点选。**

| 项 | 方式 |
|-----|------|
| 换过屏幕 / 电池 / 摄像头吗 | 店员问，点选 |
| 缺原装配件（充电器 / 线 / 盒子） | 店员点选 |
| 充电口能不能充电 | 店员点选（H5 现在不测充电口，以后可加） |

## 优化前后对比（店员要手点的东西少了哪些）

| 检测项 | 现在 | 优化后 |
|--------|------|--------|
| 屏幕显示（纯色画面） | 硬件自动 + 单独卡片手动勾 D1-D6 | 合并成一步：H5 放画面 + 店员只目视打分 |
| 屏幕触控 | 硬件自动 + 卡片手动勾 D6 | 只留 H5 自动，删掉 D6 手动勾 |
| 电池鼓包 | 准入查一次 + 外观再勾一次 | 合并，一次判定联动 |
| 摄像头 / 扬声器 / 麦克风 | 硬件 H5 测 + 功能缺陷再手动勾 | H5 覆盖，删掉手动勾 |
| 外观磨损（划痕/凹痕/裂纹） | AI 自动勾（已是这样） | 保持 AI，店员只确认 |
| 维修史 / 配件 | 手动点选 | 保持手动（机器测不了） |

**结论**：改完后，店员真正要「手点」的只剩 —— 屏幕缺陷目视打分、维修史、配件缺失、充电口功能（暂），其余全由 USB / H5 / ADB / AI 自动完成。
