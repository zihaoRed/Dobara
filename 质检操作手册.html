1. 手册说明与岗位要求

1.1 质检工具是什么

质检工具是门店回收作业的核心设备（Android 定制一体机，不限定平板形态）。店员用它完成旧机回收的标准质检：从用户身份验证开始，依次完成外观影像采集、硬件自动审计、发票信息采集，再将数据综合上传至云端；云端定价后，展示质检报告和抵扣报价供店员与用户当面确认。

1.2 岗位基本要求

要求说明
账号需有门店管理员预置的店员账号（ROLE-CLK），登录方式为手机号 + OTP / 密码
门店上下文质检工具不与门店绑定，门店信息自动从登录店员的所属门店解析
用户在场全程需用户在场知情配合；涉及"按 # 键""确认核销"等操作由店员引导完成
流程纪律流程不可跳步，每步完成后才能进入下一步；数据本地优先，上传成功后才清理
一人一单每名店员同一时间只允许一个进行中的质检会话

1.3 关键术语

术语含义
OTP一次性 6 位数字验证码，通过 SMS 发送到用户手机，有效期 3 分钟
session_id云端为本次到店质检会话分配的唯一标识
IMEI设备国际移动设备识别码（15 位数字），是回收设备的唯一标识
H5 检测页云端部署的轻量 Web 检测页（check.dobara.in），在被检手机浏览器中执行交互类检测
ADB质检工具通过 USB 与被检 Android 手机通信的调试通道
扣款代码定价引擎按缺陷档位扣除回收金额的编码（如 CO-GLS-03 表示屏幕玻璃浅划痕）
成色等级A / B / C / D 四级，外观评级越高（A 级）回收价越高

2. 质检全流程总览

店员登录质检工具
  → 用户 OTP 验证（步骤 1）
    → 加载预约信息（步骤 2，如有）
      → 外观拒收判断（步骤 3，拍照前）
          ├── 外观明显不可回收 → 拒收流程（见步骤 3）
          └── 外观可回收 → 外观影像采集（步骤 4：10 张照片 + 1 段视频）
                            → 外观 AI 检测 / 手动点检（步骤 5）
                              → 硬件自动审计（步骤 6：USB + H5）
                                → 发票信息采集（步骤 7，可选）
                                  → 综合数据上传（步骤 8）
                                    → 质检报告展示（步骤 9，云端回传）
                                      → 用户接受 / 拒绝报价
                                          └── 接受 → 核销状态同步（步骤 10）

核心设计原则（务必牢记）

  1. 流程不可跳步——每个步骤必须完成后才能进入下一步。
  2. 数据本地优先——采集数据先存本地，上传成功后清理。
  3. 断点续检——任意环节中断后，可从上次完成点恢复。
  4. 离线可用——网络中断时核心质检流程不中断。
  5. 状态可追溯——每次操作的店员、时间、设备信息全程记录。
1

到店用户 OTP 验证

对应 PRD：TAB-P0-07

操作目的

所有到店用户（无论是否预约）统一通过「手机号 + OTP」验证身份，建立本次到店会话。

操作步骤

  1. 质检工具启动后，进入店员登录页，输入本人手机号登录。
  2. 在质检工具工作台输入用户手机号。
  3. 系统校验手机号格式（10 位印度手机号，以 6/7/8/9 开头）。
  4. 系统向用户发送 SMS：包含 6 位 OTP + H5 跟踪短链。
  5. 用户告知店员 OTP（或出示手机屏幕），店员在质检工具输入 6 位 OTP。
  6. 系统验证 OTP：验证通过 → 进入步骤 2；验证失败 → 提示"OTP 错误，剩余重试 X 次"。

店员登录说明（TAB-P0-12）

项目说明
登录方式手机号 + OTP（默认），支持设置密码后用密码登录
权限校验非店员账号（如店老板 / 库管账号）登录时提示"无权限，请联系管理员添加"
登录安全连续 5 次登录失败锁定 15 分钟
Token 有效期8 小时（一个班次），过期需重新登录
多店员共用同一质检工具支持多名店员共用，各自会话相互隔离

关键规则

规则项说明
统一入口所有用户到店统一走手机号 + OTP，不再区分预约 / 到店
OTP 长度6 位数字
OTP 有效期3 分钟，过期需重新发送；界面展示剩余有效秒数倒计时
发送渠道MSG91 SMS（优先），WhatsApp Business API（备选，SMS 失败时自动切换）
重试次数最多 3 次错误输入；超过后 60 秒冷却，冷却期间输入框禁用
每日上限同一手机号每天最多发送 5 次 OTP
频率限制同一手机号两次发送间隔 ≥ 30 秒
会话生命周期自创建起 2 小时内有效；超时未完成质检会自动过期，需重新 OTP 验证
2

加载预约信息

对应 PRD：TAB-P1-02

OTP 验证通过后，系统自动以手机号查询预约信息。有预约时自动加载，作为质检辅助参考；无预约时直接进入空白新会话。

展示内容（如有预约）

信息类别展示内容
用户信息姓名、手机号（脱敏中间 4 位）、预约时间
旧机自填品牌、型号、颜色、内存 / 存储、是否在保、使用时长、电池健康（自估）、外观磨损、维修记录、功能性问题
初步估价价格区间（如"₹8,000 - ₹12,000"），标注"初步估价仅供参考"
预约备注用户填写的额外说明（如有）

关键规则

规则项说明
触发时机OTP 验证通过时自动查询，无需额外操作
有预约自动加载并展示预约信息卡片
无预约展示"新用户，无预约记录" + 空白会话，直接开始质检
多预约同一手机号当天多条预约时，展示最近一条 + "查看其他预约(N)"入口
用途定位预约信息仅供参考，不替代实际质检；旧机自填可与实际检测结果并排对比
匹配失败预约匹配失败（网络异常）不阻塞流程，自动降级为无预约模式
3

外观拒收判断（拍照前）

对应 PRD：TAB-P0-08

会话创建后、拍照开始前，店员先上手目视检查设备，判断是否可回收。不可回收设备不再浪费 10 张照片 + 视频的采集工时。

操作步骤

  1. 上手目视检查设备（正面、背面、侧面、接口、机身）。
  2. 做出判断：外观可回收 → 点击"继续拍照"（绿色主按钮）；外观明显不可回收 → 点击"拒收该设备"。
  3. 拒收流程：拍摄损坏细节照片（最少 3 张，最多 10 张：含 1 张正面全景、1 张背面全景、至少 1 张损坏细节特写）→ 从预设列表单选拒收原因（见附录 B）→ 如选"其他"填写说明（≥ 10 字）→ 点击"确认拒收" → 二次确认弹窗 → 确认后上传，会话标记 [已完成-拒收]。
  4. 店员告知用户拒收原因，当面归还设备。

关键规则

规则项说明
操作时机会话创建后第一步（拍照前）
照片要求最少 3 张，最多 10 张；必须含正面全景 + 背面全景 + 至少 1 张损坏细节特写
拒收原因单选预设项，不可自由输入（"其他"需文字说明）
不可撤销确认拒收后不可撤回，设备无法重新进入质检
不计库存拒收设备不创建 IMEI 库存记录
时间限制拒收判断在拍照前；准入检查检出进水 / 腐蚀仍可拒收；一旦开始硬件功能检测，不可再拒收
4

外观影像采集

对应 PRD：TAB-P0-01

用质检工具内置相机，对旧机做标准化外观影像采集：固定 10 张照片（10 个角度）+ 1 段 360° 旋转视频。

拍照顺序（必须严格按序）

序号角度序号角度
1正面屏幕6右
2背面后盖7左上角
3前8右上角
4后9左下角
5左10右下角
每个角度拍摄完成后自动切换到下一个角度引导；每张照片可单独重拍，不限次数。

视频要求

项目要求
时长最短 10 秒，最长 30 秒
内容完整覆盖设备 360 度旋转
不足处理不足 10 秒提示"录制时间不足，请重新录制"；超 30 秒自动停止

拍摄质量标准

项目要求
照片分辨率不低于 1080P（1920×1080）
视频规格不低于 720P / 30fps
照片格式JPEG（质量 ≥ 85%）
视频格式MP4（H.264 编码）

拍摄质量实时检测（TAB-P1-03）

检测项不达标反馈达标反馈
模糊度取景框红色 + "画面模糊，请保持稳定"绿色 + "清晰"
光线亮度取景框黄色 + "光线不足，请补光" + 闪光灯建议绿色
角度偏差叠加层边缘红 + 方向箭头归位 + "请对齐参考线"绿色 + "角度正确"
遮挡检测遮挡区域高亮红 + "请勿遮挡设备"无提示
质量不达标时不强制阻止拍照，但会红色提示；可在确认弹窗选"仍要拍摄"。建议尽量等取景框变绿再拍。
4.5

到店准入检查（客观检测 + 用户问询）

对应 PRD：TAB-P0-15

影像采集完成后、外观点检之前，平板进入到店准入检查页，分两部分：

① 客观检测

设备连接后自动查询 IMEI 黑名单 / iCloud·FRP / CEIR 报失 / 运营商锁 / EMI 分期；主板目视（腐蚀 / LCI 进水指示器 / 维修痕迹）由店员开壳检查勾选——腐蚀或 LCI 触发即拒收，维修痕迹走扣款不拒收。

② 用户问询（自报 7 项，与 C 端预约页同款问题）

场景操作
有预约预约单自报结果自动预填并标"来自预约"；店员逐项与用户核对，可纠正（纠正项自动标注「自报不符」留痕）
walk-in（无预约）店员逐项询问用户后点选，7 项全部作答后"继续"才可用
命中即强制拒收：任一问命中拒收答案（如"无法退出账号""进过水"）→ "Reject Device" 为唯一可用操作，无覆盖通道——到店以当场申报为准。拒收原因默认带入对应项，走步骤 3 的拒收流程。
5

外观 AI 检测 / 手动点检

对应 PRD：TAB-P0-13

对采集的外观影像做缺陷识别，输出 5 大维度 27 项缺陷的成色等级判定，供定价引擎扣款。

两种模式

模式适用场景说明
AI 自动检测 + 人工审核AI 服务可用（目标态）AI 从影像自动识别缺陷并返回结果，店员审核确认 / 修正
手动点检AI 未就绪 / 网络中断店员对照判定标准逐项手动勾选（见附录 A）
AI 服务不可用时会自动降级为手动点检模式，降级对店员透明（仅提示"AI 暂不可用"）。

店员审核流程（AI 模式）

  1. 快速浏览：查看 AI 检测结果汇总（5 个维度的通过 / 待确认概览）。
  2. 聚焦待确认项：点击"查看全部待确认项"，逐项审核低置信或疑似缺陷项（可确认 AI 结果 / 修正等级 / 标记"AI 误判"）。
  3. 抽查高置信项：可展开任何已通过维度抽查标注照片。
  4. 手动模式切换：AI 结果不可信时（罕见）可"切换到手动"逐项点检。
  5. 确认提交：所有待确认项处理完毕 → "确认全部" → 结果上传。

AI 置信度分级

置信度含义店员处理方式
≥ 90%高置信，AI 确定自动填充，无需逐项确认（仅汇总展示）
70-90%中置信，AI 判断自动填充，黄色高亮，需扫一眼确认
< 70%低置信 / AI 不确定红色高亮，标记"待人工判定"，必须手动选择
N/AAI 无法判断强制人工判定

关键规则

规则项说明
AI 优先，人工兜底服务端 AI 可用时默认走 AI 模式；AI 不可用自动降级手动模式
高置信自动通过置信度 ≥ 90% 且非拒收等级 → 自动填充
拒收不豁免即使 AI 高置信判为"粉碎性碎裂"，仍需店员二次确认后才能触发拒收
修正留痕店员对 AI 结果的任何修改均记录：原 AI 判断、人工修正值、操作时间、店员 ID
手动模式必选27 项按 5 维度分组，每项必须选择后方可提交
返回重拍确认返回重拍需二次确认（会清除点检进度）

硬件自动审计

对应 PRD：TAB-P0-02 + TAB-P0-14

通过 USB OTG 连接被检手机，自动运行硬件检测，覆盖 10 项核心硬件项。

连接方式

平台连接方式网络保障
AndroidUSB OTG 数据线直连，走 ADB质检工具自动开启 USB 网络共享（零配置即插即用）
iOSUSB 连接，走 libimobiledevice质检工具开启 WiFi 热点，引导用户连热点后扫码
USB 连接后 5 秒内自动开始检测，无需手动触发。

检测项目详情（10 项）

检测项检测通道输出值失败处理
IMEI / 序列号USB + 半自动暗码1-2 个 IMEI（单 / 双卡）自动重试 2 次 → 手动录入
品牌 & 型号USB品牌名 + 型号代码自动重试 2 次 → 手动录入
设备颜色店员确认颜色（单选）有预约带入预选；到店必须点选
电池健康度USB百分比（0-100%）标记"无法检测"
屏幕显示H5正常 / 缺陷等级店员标记缺陷项
屏幕触控H5正常 / 异常区域坐标标记"触控异常" + 坐标
传感器H5各传感器正常 / 异常逐传感器标记
存储容量USB总容量 GB + 可用 GB标记"无法检测"
摄像头H5正常 / 异常标记"摄像头异常（前 / 后置）"
扬声器 & 麦克风H5正常 / 异常标记异常
按键H5 引导 + ADB 判定正常 / 异常标记"按键异常（音量+/音量-/电源）"

H5 检测页操作要点

检测项H5 承担判定来源
屏幕显示全屏循环纯色画面（白 / 红 / 绿 / 蓝 / 黑 / 灰）店员目视 + H5 确认按钮
屏幕触控全屏滑涂 CanvasH5 自动判定（覆盖率 / 断线）；检出异常后 D6 自动带出"系统检出"并锁定
扬声器播放测试音（左右声道分开）店员听感确认
麦克风录音回放店员听感确认

传感器三轴引导动画（α 平转 / β 俯仰 / γ 横滚）H5 自动判定（逐轴累计角度达标）
物理按键显示"请按音量+ ×3 / 电源键 ×1"引导质检工具 ADB 监听按键事件判定

关键规则

规则项说明
检测顺序先读静态信息（IMEI / 型号 / 存储），再执行交互式测试（触控 / 按键 / 音视频）
超时处理单项超 30 秒无响应 → 标记"检测超时" → 自动重试 1 次 → 仍超时则跳过继续
失败重试单项失败自动重试最多 2 次（含首次共 3 次尝试）
不可跳过所有检测项必须执行；超时 / 失败项自动标记后继续
复测支持单项复测，复测结果覆盖原结果
颜色确认有预约自动带入；到店用户必须点选颜色后才能继续
权限拒绝摄像头 / 麦克风 / 传感器授权被拒时记录"未授权"，不判为硬件损坏
反作弊H5 上报机型与 ADB 读取交叉比对，不一致时黄色警告要求复核

IMEI 半自动暗码采集（Android）

  1. 质检工具打开拨号盘并逐键代输 *#06。
  2. 界面显示"请按 # 键"大字引导，质检员拿用户手机按下 # 触发弹窗。
  3. 质检工具 ADB 截屏 + 端侧 OCR 识别 IMEI。
  4. Luhn / 格式校验通过后回填，脱敏展示；失败自动重试 1 次，仍失败转人工读屏录入。
关键原则：暗码最后一位 # 统一由店员操作，保证"店员操作、用户在场知情"口径一致。
7

发票信息采集（可选）

对应 PRD：TAB-P0-09

询问用户是否携带设备购买发票。发票信息用于定价引擎计算基准价 min(发票价格, 市场基准价)。

操作步骤

  1. 硬件审计完成后，质检工具提示"用户是否提供购买发票？"。
  2. 提供 → 拍摄发票照片 → 录入金额 + 购买日期 → 预览确认 → 进入上传；跳过 → 直接进入综合上传。

录入字段

字段录入方式必填校验规则
发票照片拍照必填（如录入）需清晰可辨金额和日期；分辨率 ≥ 1080P
发票金额手动输入必填（如录入）INR 正整数，范围 1-999,999；以发票最终成交价为准
购买日期日期选择器必填（如录入）不可晚于今天，不可早于设备出厂日期

关键规则

规则项说明
可选操作不提供发票不影响质检流程
不可后补综合上传完成后不可再补录发票
不做真伪校验MVP 阶段仅采集，不接入 GST 发票验证
定价影响min(发票价格, 市场基准价)
上传前确认录入完成后展示预览，确认后不可返回修改

数据分类内容格式

上下文信息门店 ID + 操作店员 ID + 时间戳JSON

关键规则

规则项说明

上传失败本地数据完整保留，支持手动重试

附录 A：手动点检标准（27 项）

当 AI 服务不可用时，店员需按以下标准逐项手动点检。AI 检测的判定规则亦以此为准。

维度一：屏幕显示缺陷（D1-D6）

检测方法：H5 检测页全屏循环纯色画面（白 / 红 / 绿 / 蓝 / 黑 / 灰），店员现场目视判定（D6 触摸由 H5 触控测试覆盖）；断网降级时用正面上电图目视。

编号点检项等级判定标准扣款代码
D1显示老化 / 烧屏无 → 轻微 → 明显轻微：仅纯色背景可见残影；明显：大面积黄斑 / 图标烙印CO-DSP-01 / CO-DSP-02
D2亮点 / 坏点无 → 1-2 个 → ≥3 个1-2 个（直径<0.5mm）；≥3 个或有彩线CO-DSP-03 / CO-DSP-04
D3屏幕变色 / 偏色无 → 轻微 → 明显轻微局部偏色；大面积明显偏色CO-DSP-05 / CO-DSP-06
D4显示闪烁无 → 偶尔 → 频繁 / 持续偶尔闪烁；频繁或持续闪烁CO-DSP-07 / CO-DSP-08
D5液晶漏液 / 漏光无 → 边缘漏光 → 漏液边缘漏光；漏液（黑色 / 紫色斑块）CO-DSP-09 / CO-DSP-10
D6触摸功能正常 → 局部不灵敏 → 大面积失灵局部不灵敏；大面积失灵（>30%）触发拒收CO-DSP-11 / CO-DSP-12（拒收）

D6 锁定：H5 滑涂测试检出触控异常时，D6 自动带出"系统检出"并锁定为局部不灵敏档，不可人工改判（复测通过后自动解除）。同一触控故障只计一次扣款，请勿再手动选择。

维度二：屏幕玻璃缺陷（G1-G4）

检测方法：熄屏，45° 角，30cm 距离观察。

编号点检项等级判定标准扣款代码
G1划痕深度无 → 发丝纹 → 浅 → 深发丝纹：仅反光角可见，指甲无阻纳；浅：肉眼可见，指甲有阻纳；深：明显卡顿，伤及玻璃层CO-GLS-01 / 02 / 03
G2划痕数量无 → 少量 → 较多 → 密集少量 1-5 条；较多 6-15 条；密集 16+ 条大面积磨花CO-GLS-04 / 05 / 06
G3玻璃碎裂无 → 边缘 → 显示区 → 粉碎性边缘碎裂；显示区碎裂；粉碎性（触发拒收）CO-GLS-07 / 08 / 09（拒收）
G4玻璃脱胶 / 翘起无 → 轻微 → 明显轻微（缝隙<0.5mm）；明显（可插入纸片，触发拒收）CO-GLS-10 / 11（拒收）

维度三：机身边框缺陷（B1-B7）

检测方法：正常光线下旋转观察。

编号点检项等级判定标准扣款代码
B1掉漆 / 氧化无 → 轻微 → 明显轻微（≤3 处，单处<2mm²）；明显（>3 处或单处>5mm²）CO-BDY-01 / 02
B2磕碰凹陷无 → 轻微 → 明显轻微（1-2 处，深<0.5mm）；明显（≥3 处或深≥0.5mm）CO-BDY-03 / 04
B3边框变形无 → 轻微 → 明显轻微（翘起<2mm）；明显（目视弯曲，翘起≥2mm）CO-BDY-05 / 06
B5天线注塑条完好 → 轻微磨损 → 断裂 / 缺失—CO-BDY-09 / 10
B6拆修痕迹完好 → 螺丝有拧痕 → 螺丝缺失螺丝有拧痕 / 易碎贴破损；螺丝缺失CO-BDY-11 / 12
B7边框划痕无 → 轻微 → 明显轻微（反光角可见）；明显（指甲有阻纳）CO-BDY-13 / 14

B4「按键松动」已取消：按键故障统一在维度五的 P3 音量键 / P4 电源键 / P6 其他按键点检，不要在机身边框维度重复勾选。

维度四：后盖与机身（RC1-RC5）

检测方法：按玻璃 / 塑料 / 金属材质区分。

编号点检项等级判定标准扣款代码
RC1后盖划痕（玻璃）无 → 轻微 → 明显轻微（反光角可见）；明显（指甲有阻纳）CO-BCK-01 / 02
RC2后盖碎裂（玻璃）无 → 局部 → 大面积局部；大面积（>30% 或有脱落风险）CO-BCK-03 / 04
RC3后盖磨损（塑料 / 金属）无 → 轻微 → 严重轻微（正常痕迹）；严重（涂层剥落 / 氧化）CO-BCK-05 / 06
RC4后盖鼓包无 → 轻微 → 明显轻微（平放晃动）；明显（屏幕被顶起，触发拒收）CO-BCK-07 / 08（拒收）
RC5摄像头镜片无 → 轻微 → 明显轻微（不影响成像）；明显（影响成像）CO-BCK-09 / 10

维度五：接口与按键（P1-P6）

检测方法：目视 + 功能测试。

编号点检项等级判定标准扣款代码
P1充电口正常 → 松动 → 损坏松动；损坏 / 接触不良（pin 针弯曲）CO-PRT-01 / 02
P2数据口腐蚀无 → 轻微氧化 → 明显腐蚀轻微氧化（变暗）；明显腐蚀（绿 / 白异物，触发进水评估）CO-PRT-03 / 04
P3音量键正常 → 松软 → 失灵 / 卡死—CO-PRT-05 / 06
P4电源键正常 → 松软 → 失灵 / 卡死—CO-PRT-07 / 08
P5耳机 / 扬声器孔正常 → 积灰 → 网罩破损积灰；网罩破损 / 异物堵塞CO-PRT-09 / 10
P6其他按键（静音拨键 / Action 键等）正常 → 松软 → 失灵 / 卡死—CO-PRT-11 / 12

P6 说明：除音量键、电源键外的物理按键（iPhone 静音拨键、Action 键及 Android 侧边功能键）。此类按键不在硬件自动审计范围内，只能由本项人工点检，请勿在其他维度重复勾选。

附录 C：常见问题（FAQ）

问题答案 / 处理
用户收不到 OTP 短信怎么办？确认手机号是否 10 位印度手机号；可请求重发（间隔 ≥ 30 秒）；短信失败会自动切换 WhatsApp 发送
OTP 输错多次被锁了怎么办？3 次错误后 60 秒冷却，期间等待倒计时结束即可重试
用户没有预约能质检吗？可以，OTP 验证后直接进入空白新会话，不影响质检
拍照光线不足但必须拍怎么办？质量不达标不强制阻止，可在确认弹窗选"仍要拍摄"，但建议尽量补光后再拍
USB 连接后没反应？检查 USB OTG 线是否插紧；断开后界面会提示"设备已断开，请重新连接"，重连后自动继续
检测到一半网络断了？核心质检流程不中断，数据暂存本地，恢复后自动补传；交互项标记"待网络恢复"
报价超过 30 分钟还没让用户决定？报价失效，需重新质检生成新报价
用户拒绝报价后还能再质检吗？报价拒绝后该订单状态独立，需按流程重新质检生成新报价
可以补录发票吗？不可以，综合上传完成后不可再补录发票
拒收后反悔了能撤销吗？不能，拒收不可撤销
为什么要店员按 # 键而不是用户自己按？保证"店员操作、用户在场知情"口径一致，避免用户误操作
质检中断了怎么继续？重新打开 App，检测到未完成会话会弹恢复提示，选"继续"即可（24 小时内有效）
