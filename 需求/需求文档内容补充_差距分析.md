# 需求文档内容补充 — 差距分析

> 对照当前 [功能描述文档.md](../功能描述文档.md)，逐条分析需求补充文档中的遗漏点

---

## 一、TAB — 平板质检工具

| 编号 | 需求 | 优先级 | 当前覆盖情况 | 差距 |
|------|------|:---:|------|------|
| TAB-01 | 平板固件/App OTA 更新 | P0 | ❌ 未覆盖 | **严重缺失**。当前零覆盖——质检 App 如何更新、检测脚本如何升级完全没有定义。没有 OTA，一个 Bug 修复需要派人到每个门店手动更新。建议新增 `TAB-P0-10 OTA 远程更新` |
| TAB-02 | 质检中断与恢复 | P0 | ⚠️ 部分覆盖 | TAB-P1-01 只覆盖了"网络中断→离线缓存"，但**不覆盖**：App 崩溃、平板断电、USB 意外断开后的断点续检。当前设计是整个质检重来。需补充"每步完成时持久化检查点"逻辑 |
| TAB-03 | 拍摄质量实时检测 | P1 | ❌ 未覆盖 | TAB-P0-01 只管拍照，不管拍得好不好。需补充：模糊检测、光线不足提示、角度偏离引导、实时反馈 |
| TAB-04 | 单项检测失败处理 | P0 | ⚠️ 部分覆盖 | TAB-P0-02 有"超时→标记超时→跳过"，但**缺失**：(1) 是否支持手动补录该单项？(2) 跳过项是否影响定价（当前定价引擎会因传感器标记"异常"而扣款）？(3) 重试策略和次数 |
| TAB-05 | 质检工具交互细节 | P1 | ⚠️ 部分覆盖 | 每个检测项有流程描述，但具体 UI 交互（按钮位置、确认弹窗、进度动画、错误提示样式）未定义 |
| TAB-06 | 外观拒收照片上限 | P1 | ⚠️ 需修正 | TAB-P0-08 规定"≥3 张，无上限"。**确实不合理**——店员可能拍 50 张拖慢上传。建议上限 10 张 |
| TAB-07 | 离线缓存清理+平板注册登录 | P0/P2 | ❌ 严重缺失 | **两个独立问题**：(1) 离线缓存何时清理、清理规则未定义；(2) **平板注册登录 P0——整个功能描述文档零覆盖**：店员如何登录平板？店员和门店的绑定关系？多店员共用同一平板的会话隔离？离职换班的权限回收？必须新增 |
| TAB-09 | 质检数据列表 | P1 | ❌ 未覆盖 | 多台设备同时/先后质检时，平板没有质检记录列表。店员无法回看历史质检、无法继续未完成的会话 |
| TAB-10 | 数据看板细化 | P2 | ⚠️ 部分覆盖 | TAB-P2-01 只有三项基础指标（回收量/成交金额/驳回率），缺：日期筛选、图形化展示、更细粒度指标 |

## 二、APP — C 端用户 App

| 编号 | 需求 | 优先级 | 当前覆盖情况 | 差距 |
|------|------|:---:|------|------|
| APP-01 | 用户注册与登录 | P0 | ❌ 严重缺失 | **整个用户体系的入口零覆盖**。已覆盖到店 OTP 验证，但 App 端的注册（手机号 OTP 注册/密码设置/密码规则）、登录（账号密码/验证码）、用户协议确认全都没有。这是所有 C 端功能的前置依赖 |
| APP-02 | 个人中心 | P0 | ❌ 未覆盖 | 收货地址管理、支付方式管理、账户安全/注销——订单流程的前置依赖 |
| APP-03 | 搜索与筛选细化 | P0 | ⚠️ 部分覆盖 | APP-P0-03 有基本筛选（品牌/机型/成色/价格），但**缺失**：搜索底词/联想词、搜索逻辑、无结果兜底、模糊搜索策略 |
| APP-04 | 客服/帮助中心 | P1 | ⚠️ 仅在辅助需求 | 辅助需求文档有提及，但功能描述文档未定义 |
| APP-05 | 订单取消 | P0 | ❌ 未覆盖 | APP-P0-04 只有下单支付流程，**无取消流程**：待支付取消（释放锁）、待发货取消（退款规则）、已发货取消 |
| APP-06 | 评价系统 | P2 | ❌ 未覆盖 | — |
| APP-07 | 设备对比 | P2 | ❌ 未覆盖 | — |
| APP-08 | 收藏/心愿单 | P2 | ❌ 未覆盖 | — |
| APP-09 | App 设置 | P1 | ❌ 未覆盖 | 语言切换、通知偏好、关于/版本、缓存清理、用户协议、隐私政策入口 |
| APP-10 | 库存锁单节点修正 | P1 | ⚠️ 设计缺陷 | 当前 APP-P0-04 在"立即购买"即加锁。标准电商流程是"点击立即购买→确认订单页→提交订单→加锁→支付"。当前设计会让用户仅浏览就被锁单 |
| APP-11 | 支付模块细节 | P0 | ❌ 严重缺失 | CLOUD-P0-06 覆盖了后端 Razorpay 集成，但 **App 端订单确认页完全缺失**：收货地址、商品金额明细、配送方式、支付方式选择、支付失败重试 UI。没有这个页面下单流程走不通 |
| APP-12 | 售后体系 | P0 | ❌ 严重缺失 | **零覆盖**。退货原因分类、举证上传、退货物流、退款流程与时效、换货流程、售后状态追踪——一个电商平台的完整售后闭环全部缺失 |
| APP-13 | 物流追踪细化 | P1 | ⚠️ 部分覆盖 | APP-P1-02 有订单列表和物流状态，但**缺失**：物流状态节点定义、预计送达时间、物流服务商信息 |

## 三、优先级汇总

### P0 级遗漏（MVP 阻塞项）—— 9 项

| 编号 | 遗漏 | 影响 |
|------|------|------|
| TAB-01 | 平板 OTA 更新 | 无法远程修 Bug |
| TAB-02 | 质检中断恢复 | 断电/USB 断开全重来 |
| TAB-04 | 单项检测失败处理 | 定价引擎依赖，缺规则会扣错钱 |
| TAB-07 | 平板注册登录 + 店员身份 | **整个平板端没有登录系统** |
| APP-01 | 用户注册与登录 | C 端用户没有注册/登录入口 |
| APP-02 | 个人中心 | 下单没有收货地址 |
| APP-05 | 订单取消 | 锁单后无法释放 |
| APP-11 | 支付模块 App 端 | 只有后端支付，App 没有确认订单页 |
| APP-12 | 售后体系 | 没有退货/退款流程 |

### P1 级遗漏（二期完善）—— 7 项

| 编号 | 遗漏 |
|------|------|
| TAB-03 | 拍摄质量实时检测 |
| TAB-05 | 质检工具交互细节 |
| TAB-06 | 外观拒收照片上限 |
| TAB-09 | 质检数据列表 |
| APP-04 | 客服/帮助中心 |
| APP-09 | App 设置 |
| APP-10 | 锁单节点修正 |
| APP-13 | 物流追踪细化 |

### P2 级遗漏（三期优化）—— 5 项

| 编号 | 遗漏 |
|------|------|
| TAB-07 | 离线缓存清理规则（后半部分） |
| TAB-10 | 数据看板细化 |
| APP-06 | 评价系统 |
| APP-07 | 设备对比 |
| APP-08 | 收藏/心愿单 |

## 四、建议处理顺序

```
第一批（立即补，阻塞 MVP）：
  1. TAB-07 平板登录 + 店员身份管理
  2. APP-01 用户注册与登录
  3. APP-02 个人中心（至少收货地址）
  4. APP-11 支付模块 App 端（确认订单页）
  5. APP-12 售后体系（至少退货申请+退款）
  6. APP-05 订单取消
  7. TAB-01 平板 OTA 更新
  8. TAB-02 质检中断恢复
  9. TAB-04 单项检测失败处理策略

第二批（二期完善）：
  TAB-03/05/06/09, APP-04/09/10/13

第三批（三期）：
  TAB-07后半/10, APP-06/07/08
```
