## CLOUD-P0-08 运营审核
**优先级：** P0
**功能描述：**
运营人员在 Web 后台对待上架设备进行审核。审核时对比质检影像与系统判定的成色等级及扣款项是否一致。若一致则直接上架；若不一致，运营人员直接在审核界面调整成色等级或扣款项（如降级外观、增加扣款），系统重新计算回收价和商城售价后上架。不设"拒绝上架"操作——所有设备均会上架，只是价格可能因调整而变化。
**审核流程：**

```
待上架设备进入任务队列
  → 运营人员打开审核工作台
    → 查看设备外观影像（10 张照片 + 1 段视频）+ 硬件检测摘要 + 当前成色等级 + 扣款明细
    → 判断机况是否与系统判定一致
      ├── 机况一致 → 点击"直接上架"
      │     → 上传商品主图（必填）
      │     → 设备状态 → [在库可售]
      │
      └── 机况不符 → 点击"调整后上架"展开调整面板
            → 下调成色等级 / 补勾扣款项
            → 填写调整原因（必填）
            → 系统重新计算回收价 + 商城售价
            → 上传商品主图（必填）
            → 推送调整详情至对应门店平板
            → 设备状态 → [在库可售]

```
**审核界面要素：**

| 区域 | 内容 |
|------|------|
| 任务队列 | 按入库时间排序的待审核设备列表，支持按品牌/机型/成色等级筛选 |
| 审核工作台-左侧 | 10 张外观照片可切换查看 + 视频播放器（支持暂停/拖动/全屏） |
| 审核工作台-右侧 | 硬件检测摘要（电池/屏幕/传感器/存储/摄像头/扬声器/按键）+ 当前成色等级 + 扣款明细（逐项列出） |
| 商品主图上传 | 运营从系统图片库选择或本地上传一张新机精修图作为商城商品列表主图（与质检原始照片区分），支持预览裁剪 |
| 操作区 | "直接上架"按钮（机况一致）+ "调整后上架"按钮（机况不符，展开调整面板） |
**运营调整面板（点击"调整后上架"时展开）：**

| 可调整项 | 说明 |
|----------|------|
| 成色等级 | 可下调（如 B→C、B→D），不可上调（防止虚标高等级卖高价） |
| 外观扣款项 | 可新增/修改店员未勾选的扣款项（如店员遗漏了屏幕划痕，运营可补勾 A2 扣款项） |
| 硬件扣款项 | 可新增店员漏判的硬件扣款（如店员未标记触控异常，运营从检测结果中确认后补勾） |
| 调整原因 | 必填，文本输入框，简要说明为何调整（如"屏幕划痕在视频中清晰可见，店员未勾选"），最少 10 字 |
**调整后系统自动执行：**

| 动作 | 说明 |
|------|------|
| 重新计算回收价 | 基于调整后的成色等级和新增扣款项，重新跑定价引擎（CLOUD-P0-01） |
| 重新计算商城售价 | 基于新的回收价和成色等级，重新计算挂牌售价 |
| 推送调整详情至平板 | 通知门店：调整了哪些项、原价格 → 调整后价格、调整原因（参见 TAB-P0-06） |
| 设备状态 → [在库可售] | 直接上架至商城，不阻塞流转 |
**业务规则：**

| 规则项 | 说明 |
|--------|------|
| 无拒绝操作 | 所有设备均上架，不存在"拒绝上架"按钮；极端劣质设备可通过降级+多扣款压低价格后上架 |
| 成色不可上调 | 运营仅可下调成色等级（如 B→C），不可上调（如 C→B）；上调操作被系统禁用 |
| 调整原因必填 | 任何时候选择"调整后上架"，调整原因为必填字段，不少于 10 个字符 |
| 商品主图必填 | 无论直接上架还是调整后上架，运营必须上传至少一张商品主图，未上传不可提交上架 |
| 调整可叠加 | 运营可在同一审核会话中同时下调成色等级和补勾多项扣款 |
| 不可回退 | 上架操作一旦提交不可撤回，设备立即进入在库可售状态 |
| 审核时效 | 设备入库后超过 24 小时未审核，系统在任务队列中标记"超时待审"橙色提醒 |
| 调整日志 | 所有调整操作记录操作人、时间、调整前后对比、调整原因，用于门店复盘和运营绩效考核 |
**验收标准：**
- [ ] 任务队列按入库时间倒序排列，超 24 小时未审标记橙色
- [ ] 任务队列支持按品牌/机型/成色等级筛选，筛选结果实时更新
- [ ] 审核工作台同时展示外观影像（10 张照片可点击切换 + 视频可播放/暂停/全屏）、硬件检测摘要、当前系统判定的成色等级、逐项扣款明细
- [ ] 商品主图支持本地上传（JPG/PNG，最小 800x800px）和从系统图片库选择，上传后可预览和裁剪
- [ ] 机况与系统判定一致时，运营点击"直接上架"→ 上传商品主图 → 确认提交 → 设备上架
- [ ] 机况不符时，运营点击"调整后上架"展开调整面板：可下调成色等级（不可上调）、可补勾/新增扣款项、必须填写调整原因（≥10 字）
- [ ] 调整后系统自动重新计算回收价和商城售价，审核界面实时预览新价格
- [ ] 调整详情（调整项 / 原价 / 新价 / 原因）实时推送至对应门店平板（TAB-P0-06）
- [ ] 所有操作（直接上架/调整后上架）均需上传商品主图，未上传不可提交
- [ ] 上架操作一旦提交不可撤回
- [ ] 每台上架设备记录审核人、审核时间、审核结果（通过/调整）、操作日志

## CLOUD-P0-11 平台角色与权限管理
**优先级：** P0
**功能描述：**
平台系统管理员通过运营后台管理各端用户角色与权限。系统分为四个端，每个端对应不同角色和功能集。管理员可在后台创建角色、为角色配置功能权限、管理各端账号、维护门店/仓库数据隔离规则。同一账号可拥有多个角色，登录后可在 App/Web 内切换角色视图。
**四端架构：**

| 端 | 角色 | 覆盖范围 | 说明 |
|------|------|----------|------|
| **用户端** | 消费者 | C 端 App / H5 | 换购预约、质检报告查看、接受/拒绝报价、商城浏览与购买（个人+企业）、订单与物流追踪 |
| **店老板端** | 店老板 | 店老板 App | 核销确认（录入新机售价、确认核销）、门店营收查看、B2B 采购、店员管理（添加/移除店员账号） |
| **DB 端** | DB（财务/结算） | DB App / Web | 资金结算审核、门店对账、换购凭证审核、佣金核算、异常交易标记 |
| **库管端** | 仓库管理员 | 仓库 App / Web | 设备入库确认、出库任务处理、扫码核销 IMEI、打印面单、库存查询与盘点 |
**角色管理功能：**

| 功能 | 说明 |
|------|------|
| 新建角色 | 输入角色名称、描述、所属端（四端之一或跨端），勾选该角色可访问的功能模块集合 |
| 编辑角色 | 修改角色名称、描述、权限集合；修改后持有该角色的所有账号权限实时同步 |
| 删除/停用角色 | 不可物理删除已有账号关联的角色，支持停用（停用后持有该角色的账号失去对应权限） |
| 角色列表 | 按端筛选，展示角色名称、描述、关联账号数、创建时间 |
| 权限预览 | 选中角色后展示该角色在各功能模块的权限明细 |
**账号管理功能：**

| 功能 | 说明 |
|------|------|
| 创建账号 | 输入手机号（作为登录账号）→ 设置初始密码 → 选择所属端 → 分配一个或多个角色 → 绑定门店/仓库（如需隔离） |
| 编辑账号 | 修改角色分配、门店/仓库绑定、启用/禁用状态 |
| 禁用账号 | 禁用后该账号立即无法登录对应端，保留历史操作记录 |
| 账号列表 | 按端/门店/仓库筛选，展示手机号、姓名、角色、状态（启用/禁用）、最近登录时间 |
| 重置密码 | 管理员可为账号重置密码，系统发送新密码至绑定手机号 |
**权限矩阵（默认模板，管理员可自定义）：**

| 功能模块 | 用户端 | 店老板端 | DB 端 | 库管端 |
|----------|:---:|:---:|:---:|:---:|
| 换购预约 + 报告 + 报价 | Y | — | — | — |
| 商城浏览 + 下单支付 | Y | Y (B2B) | — | — |
| 核销确认 | — | Y | — | — |
| 店员账号管理 | — | Y | — | — |
| 门店营收查看 | — | Y | — | — |
| 资金结算对账 | — | — | Y | — |
| 换购凭证审核 | — | — | Y | — |
| 异常交易标记 | — | — | Y | — |
| 佣金核算 | — | — | Y | — |
| 授信额度管理（查看） | — | Y | Y | — |
| 仓库入库/出库 | — | — | — | Y |
| 库存管理 | — | — | — | Y |
| 面单打印 | — | — | — | Y |
| 退货鉴定 | — | — | — | Y |
| 运营审核 | — | — | — | —（运营后台专有） |
| 数据报表 | — | — | — | —（运营后台专有） |
| 设备品类管理 | — | — | — | —（运营后台专有） |
| 角色权限管理 | — | — | — | —（系统管理员专有） |
**多角色切换：**

| 场景 | 说明 |
|------|------|
| 同一账号多角色 | 如某员工同时持有店老板角色 + DB 角色，登录后在 App/Web 右上角可切换角色视图 |
| 切换行为 | 切换角色后刷新界面，展示该角色对应端的功能菜单和数据范围 |
| 权限并集 | 多角色时，账号在各端的实际权限为该端所有角色的权限并集 |
| 切换日志 | 角色切换操作记录日志（账号、切换时间、切换前角色、切换后角色） |
**门店/仓库数据隔离：**

| 规则项 | 说明 |
|--------|------|
| 门店隔离 | 店老板仅可查看和管理自己门店的数据（店员、换购记录、营收），绑定门店 ID 实现 |
| 仓库隔离 | 仓库管理员仅可查看和管理自己所在仓库的库存和任务，绑定仓库 ID 实现 |
| DB 跨门店 | DB 可跨门店查看结算数据，但不可操作门店的质检或核销流程（只读权限） |
| 跨门店账号 | 特殊场景（如区域经理）可配置跨门店/跨仓库数据查看权限，需管理员单独授权 |
| 数据范围变更 | 管理员修改账号的门店/仓库绑定后，账号下次登录时数据范围即时生效 |
**业务规则：**

| 规则项 | 说明 |
|--------|------|
| 权限粒度 | 按"端 + 功能模块"控制，管理员在后台为角色勾选可访问的功能模块 |
| 权限变更即时生效 | 角色权限修改后，持有该角色的所有在线账号即时生效，无需重新登录 |
| 默认角色 | 系统预置四类默认角色（消费者/店老板/DB/库管），不可删除，仅可修改权限 |
| 管理员账号保护 | 系统管理员账号由系统初始化创建，不可被其他管理员禁用或删除 |
| 操作日志 | 所有角色创建/修改/删除、账号创建/禁用/权限变更操作均记录审计日志 |
**验收标准：**
- [ ] 管理员可在运营后台创建/编辑/停用角色，每个角色可勾选各功能模块权限
- [ ] 管理员可创建/编辑/禁用四端账号，每个账号可分配一个或多个角色
- [ ] 同一账号多角色时，登录后可在 App/Web 内右上角切换角色视图，切换后刷新功能菜单和数据范围
- [ ] 店老板仅可查看本门店数据，不可跨门店访问
- [ ] 仓库管理员仅可查看本仓库数据，不可跨仓库访问
- [ ] DB 可跨门店查看结算数据但不可操作门店业务（质检/核销/店员管理入口不可见）
- [ ] 角色权限变更后实时生效，在线用户无需重新登录
- [ ] 账号禁用后即时无法登录，正在使用中的会话在 5 分钟内自动登出
- [ ] 系统预置默认角色不可删除
- [ ] 所有权限管理操作记录审计日志

## CLOUD-P1-05 审核历史与效率统计
**优先级：** P1
**功能描述：**
运营后台提供审核历史查询和审核效率统计功能。运营主管可按时间范围、门店、审核人维度筛选历史审核记录，查看每台设备的审核详情（审核人、审核时间、审核结果、调整项）。效率统计按审核人汇总人均审核量和平均审核时效，支持数据导出，用于运营团队绩效考核和工作量管理。
**审核历史查询：**

| 筛选项 | 说明 |
|--------|------|
| 时间范围 | 日期选择器，支持快捷选择（今日/昨日/本周/本月/自定义） |
| 审核人 | 下拉多选，列出所有具备审核权限的运营人员 |
| 审核结果 | 下拉单选：全部 / 直接上架 / 调整后上架 |
| 门店 | 下拉多选，按门店筛选设备来源 |
| 品牌/机型 | 下拉筛选，级联选择 |
| 成色等级 | 多选 A/B/C/D |
**审核历史列表字段：**

| 字段 | 说明 |
|------|------|
| 设备标识 | 品牌 + 型号 + IMEI 后四位 |
| 来源门店 | 回收门店名称 |
| 原成色等级 | 系统判定或店员评定的原始等级 |
| 审核后成色等级 | 审核后的最终等级（调整时展示变化箭头） |
| 审核结果 | 直接上架 / 调整后上架（标签展示） |
| 回收价变化 | 原回收价 → 调整后回收价（仅调整时展示） |
| 审核人 | 审核操作人员姓名 |
| 审核时间 | 审核提交时间 |
| 操作 | 查看审核详情（展开审核工作台回放，含影像、扣款明细、调整原因） |
**审核效率统计：**

| 统计指标 | 说明 |
|----------|------|
| 人均日审核量 | 按天统计每个审核人的审核设备数量 |
| 人均周/月审核量 | 按周/月聚合统计 |
| 平均单台审核耗时 | 从打开审核工作台到点击提交的时间差 |
| 直接上架率 | 直接上架数 / 总审核数（机况一致性指标，可间接反映门店质检质量） |
| 调整率 | 调整后上架数 / 总审核数 |
| 常见调整项分布 | 统计各扣款项被运营补勾的频次（如"屏幕划痕"被补勾 120 次），用于优化平板外观点检引导 |
| 各门店调整率排名 | 按门店统计其设备被运营调整的比例，识别质检质量薄弱的门店 |
**统计展示形式：**

| 展示形式 | 适用场景 |
|----------|----------|
| 汇总卡片 | 总审核量、今日审核量、平均审核耗时等核心 KPI |
| 折线图 | 审核量趋势（按天/周/月） |
| 柱状图 | 各审核人审核量对比、各门店调整率对比 |
| 饼图 | 审核结果分布（直接上架 vs 调整后上架） |
| 数据表格 | 详细审核记录列表，支持排序和导出 |
**数据导出：**

| 导出类型 | 说明 |
|----------|------|

**验收标准：**

- [ ] 效率统计数据每 5 分钟自动刷新

## CLOUD-P2-02 数据报表
**优先级：** P2
**功能描述：**
运营后台提供回收、销售、库存周转三大核心维度的数据报表。报表支持按时间范围（日/周/月/季/年）、区域、门店、品牌/机型的多维度下钻分析。数据以可视化图表和明细表格结合展示，支持导出。报表帮助运营团队掌握平台整体运营状况、识别趋势和问题、支撑业务决策。
**报表一：回收报表**

| 指标 | 说明 | 下钻维度 |
|------|------|----------|
| 回收量 | 完成核销的旧机台数 | 按门店、按品牌/机型、按成色等级 |
| 报价接受率 | 用户接受报价数 / 总报价数 | 按门店、按品牌/机型、按时间 |
| 拒收率 | 外观拒收数 / 总到店数 | 按门店、按拒收原因分布 |
| 总回收金额 | 所有核销回收的抵扣金额合计 | 按门店、按品牌/机型 |
| 平均回收价 | 总回收金额 / 回收量 | 按成色等级、按品牌/机型 |
| 预约转化率 | 实际到店数 / 预约数（P1） | 按门店、按城市 |
| 运营调整率 | 被运营调整的设备数 / 总审核数 | 按门店 |
**报表二：销售报表**

| 指标 | 说明 | 下钻维度 |
|------|------|----------|
| 销售量 | 支付成功并已发货的订单设备总数 | 按品牌/机型、按成色等级、按区域 |
| 销售额 | 所有已售设备的销售金额合计 | 按品牌/机型、按成色等级、按区域 |
| 客单价 | 销售额 / 订单数 | 按 B2C/B2B 分、按区域 |
| B2B vs B2C 占比 | B2B 订单占比 vs B2C 订单占比 | 按门店（采购方） |
| 支付成功率 | 支付成功数 / 发起支付数 | 按支付方式（UPI/授信） |
| 滞销设备 | 上架超过 14 天未售出的设备列表 | 按品牌/机型、按成色等级、按仓库 |
| 退货率 | 退货完成数 / 总售出数（P1） | 按退货原因分布 |
**报表三：库存报表**

| 指标 | 说明 | 下钻维度 |
|------|------|----------|
| 在库总量 | 当前状态为 [在库可售] 的设备数量 | 按仓库、按品牌/机型、按成色等级 |
| 入库量 | 指定时间段内入库设备数 | 按仓库、按来源门店、按时间 |
| 出库量 | 指定时间段内发货出库数 | 按仓库、按 B2C/B2B |
| 平均周转天数 | (出库时间 − 入库时间) 的平均值 | 按品牌/机型、按成色等级、按仓库 |
| 库存健康度 | 库存中 > 30 天未售出的设备占比 | 按仓库 |
| 仓库库容利用率 | 在库量 / 仓库配置容量（P2） | 按仓库 |
**报表通用功能：**

| 功能 | 说明 |
|------|------|
| 时间范围选择 | 支持日/周/月/季/年 + 自定义起止日期 |
| 对比功能 | 支持同比/环比对比（如本月 vs 上月、本月 vs 去年同月） |
| 可视化图表 | 折线图（趋势）、柱状图（对比）、饼图（占比）、数据表格（明细） |
| 下钻 | 点击图表中的聚合数据可下钻到明细列表 |
| 数据导出 | 支持导出当前报表数据为 Excel/CSV，含图表截图 |
| 定时报表 | 支持配置日报/周报/月报自动生成并通过邮件/推送发送（P2 后期） |
| 收藏视图 | 保存常用筛选条件组合为"我的视图"，一键加载 |
**业务规则：**

| 规则项 | 说明 |
|--------|------|
| 数据刷新 | 报表数据每 30 分钟刷新一次，支持手动刷新 |
| 权限控制 | 所有运营人员可查看汇总报表；门店明细需运营主管及以上权限 |
| 数据一致性 | 报表数据与 CLOUD-P0-03 设备状态机和 CLOUD-P0-04 库存管理实时数据一致 |
| 历史数据 | 报表历史数据保留至少 2 年 |
**验收标准：**
- [ ] 回收报表展示回收量、报价接受率、拒收率、总回收金额、平均回收价、运营调整率
- [ ] 销售报表展示销售量、销售额、客单价、B2B/B2C 占比、支付成功率、滞销设备、退货率
- [ ] 库存报表展示在库总量、入库量、出库量、平均周转天数、库存健康度
- [ ] 所有报表支持按时间范围、区域、门店、品牌/机型多维度筛选和下钻
- [ ] 报表页面包含折线图、柱状图、饼图和明细表格
- [ ] 图表数据支持点击下钻到明细列表
- [ ] 支持同比/环比对比功能
- [ ] 报表数据支持导出 Excel/CSV
- [ ] 每 30 分钟自动刷新数据，支持手动刷新

## CLOUD-P2-03 设备品类管理
**优先级：** P2
**功能描述：**
运营人员在后台维护品牌、型号、成色标准等基础数据字典。设备品类数据是平台正常运行的基础数据支撑——定价引擎的基准价按品牌/型号配置，商城的筛选和搜索依赖品牌/型号数据，商品详情页的参数规格 Tab 从此处读取型号模板数据。支持新增、编辑、停用品牌和型号，管理成色等级标准和规格参数模板。
**功能一：品牌管理**

| 功能 | 说明 |
|------|------|
| 品牌列表 | 展示所有已配置的品牌，含品牌名称、LOGO 图标、设备数量、状态（启用/停用） |
| 新增品牌 | 输入品牌名称（支持中英文）、上传品牌 LOGO、设置排序权重 |
| 编辑品牌 | 修改品牌名称、LOGO、排序权重 |
| 停用/启用品牌 | 停用后该品牌下的型号在新质检中不可选（历史数据保留）；启用后恢复 |
| 品牌搜索 | 按品牌名称模糊搜索 |
**功能二：型号管理**

| 功能 | 说明 |
|------|------|
| 型号列表 | 按品牌分组展示所有型号，含型号名称、发布年份、设备数量、状态 |
| 新增型号 | 选择所属品牌 → 输入型号名称 → 设置发布年份 → 配置默认属性 |
| 编辑型号 | 修改型号名称、发布年份 |
| 停用/启用型号 | 停用后该型号在新质检中不可选（历史数据保留） |
| 型号搜索 | 按型号名称模糊搜索 |
**功能三：成色等级标准管理**

| 功能 | 说明 |
|------|------|
| 等级标准查看 | 展示 A/B/C/D 四个成色等级的定义、判定规则、示例说明 |
| 编辑等级标准 | 修改各等级的判定规则文本和参考图例（用于店员培训和商城展示） |
| 参考图例管理 | 为每个等级上传典型设备的外观参考照片，用于平板质检时引导店员评级 |
| 默认不可新增等级 | 系统固定 A/B/C/D 四级，不可新增或删除等级 |
**功能四：规格参数模板管理**

| 功能 | 说明 |
|------|------|
| 模板列表 | 按型号展示已配置的规格参数模板，含 13 项标准参数项 |
| 新建/编辑模板 | 为每个型号填写参数规格值：处理器/内存/显示屏/摄像头/电池/系统/机身/连接/安全/防水/卡槽等 |
| 模板继承 | 同品牌同系列型号可继承父型号的规格参数模板，仅修改差异项 |
| 模板预览 | 预览该型号在 C 端 App 商品详情页"参数规格"Tab 的最终展示效果 |
| 批量导入 | 支持通过 Excel 模板批量导入多个型号的参数规格数据 |
**规格参数标准字段（每个型号）：**

| 分类 | 参数项 | 输入方式 |
|------|--------|----------|
| 基本信息 | 品牌、型号、发布年份 | 自动关联/手动选择 |
| 处理器 | 芯片型号、核心数 | 文本输入 |
| 内存与存储 | RAM 容量 | 文本输入（如 4GB / 6GB / 8GB） |
| 显示屏 | 尺寸、分辨率、刷新率、面板类型 | 文本输入 |
| 后置摄像头 | 像素、光圈、镜头数量 | 文本输入 |
| 前置摄像头 | 像素、光圈 | 文本输入 |
| 电池 | 额定容量 (mAh)、充电功率 | 数字 + 文本输入 |
| 操作系统 | 出厂系统版本、可升级至 | 文本输入 |
| 机身 | 尺寸、重量、材质 | 文本输入 |
| 连接性 | 5G/4G、Wi-Fi、蓝牙版本 | 多选 + 文本输入 |
| 安全认证 | Face ID / Touch ID / 无 | 单选 |
| 防水防尘 | IP 等级 | 文本输入 |
| 卡槽 | 单卡/双卡 | 单选 |
**业务规则：**

| 规则项 | 说明 |
|--------|------|
| 品牌唯一性 | 品牌名称全局唯一，不区分大小写 |
| 型号唯一性 | 同一品牌下型号名称唯一 |
| 停用保护 | 有在库设备的品牌/型号不可停用，需先清理库存 |
| 模板必填 | 参数规格模板中，品牌/型号/发布年份/处理器/显示屏/电池为必填项，其余可选填 |
| 模板生效 | 新建或修改参数规格模板后，该型号的所有设备在商城详情页立即展示更新后的规格 |
| 操作日志 | 所有品牌/型号/等级标准/模板的增删改操作记录操作人、时间、变更内容 |
**验收标准：**
- [ ] 支持新增/编辑/停用品牌，含名称、LOGO、排序权重
- [ ] 支持新增/编辑/停用型号，型号关联品牌
- [ ] 品牌/型号搜索支持模糊匹配
- [ ] 有在库设备的品牌/型号停用时提示"该品牌/型号下有 N 台在库设备，不可停用"
- [ ] 成色等级标准（A/B/C/D）可编辑描述文本和参考图例，不可新增/删除等级
- [ ] 每个型号可配置完整的 13 项参数规格模板
- [ ] 同品牌同系列型号支持模板继承，仅修改差异项
- [ ] 模板修改后，该型号所有在售设备的商品详情页同步更新
- [ ] 参数规格模板支持批量导入 Excel
- [ ] 所有数据变更记录操作日志
