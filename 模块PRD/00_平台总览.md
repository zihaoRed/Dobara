# 00 — 平台总览 | Platform Overview
> 面向：PM / 架构师 / 所有团队  
> 用途：理解全局架构、端与端之间的关系、核心流程

## 一、四端架构

```
                    ┌──────────────────────────┐
                    │   云端中台 (服务端 API)     │
                    │   定价引擎 · 状态机 · 库存   │
                    │   支付 · 路由 · 核销 · OTP  │
                    │   预约 · 授信 · i18n       │
                    └──────┬──────┬────────────┘
                           │      │
        ┌──────────────────┼──────┼──────────────────┐
        │                  │      │                  │
   ┌────▼────┐      ┌──────▼──┐ ┌─▼────────┐   ┌────▼────┐
   │ 用户端   │      │店老板App │ │ 运营后台   │   │  DB 端   │
   │ C-end   │      │Owner App │ │ Ops Web   │   │ DB Term  │
   │ iOS/And │      │ iOS/And  │ │           │   │ Web/App  │
   └─────────┘      └──────────┘ └───────────┘   └──────────┘
        │
   ┌────▼────┐      ┌──────────┐
   │平板质检  │      │ 仓库端    │
   │Tablet   │      │ WH Term  │
   │Android  │      │ Web/App  │
   └─────────┘      └──────────┘

```

| 端 | 平台 | 使用者 | 核心职责 |
|------|------|------|------|
| 用户端 Consumer | iOS + Android App / H5 | 消费者 | 换购预约、质检报告、商城浏览购买、订单追踪 |
| 门店综合 App Unified Store | iOS + Android App | 店老板 / 库管 / DB | 按角色权限显示不同模块：<br>**店老板**→核销价格录入、店员管理、营收、B2B<br>**库管**→入库、翻新、出库、核销、面单、盘点<br>**DB**→授信结算、对账、凭证审核、佣金 |
| 平板质检 Tablet | Android 定制平板 | 门店店员 | 外观拍照、硬件审计、外观点检、核销状态同步 |
| 运营后台 Ops | Web | 运营人员 | 设备审核调整、商品主图、角色权限、品类管理 |
| 云端中台 Backend | Server API | 系统 | 定价引擎、状态机、库存、支付、路由、核销、OTP、i18n |

## 二、核心业务流程

```
线上预约(1) → 到店 OTP 验证(2) → 外观采集(3-4) → 外观拒收判断(5)
  → 硬件审计(6-7) → 发票采集(8) → 数据上传(9) → 定价+报告推送(10-11)
  → 用户接受报价(12-13) → 店老板录入售价(14-15) → 用户新机确认核销(16-17)
  → DB 发旧机到仓库(18-19) → 入库确认(20) → 翻新判断(21-22)
  → 运营审核+上架(23-25) → C端浏览购买(26-31) → 仓库发货

```

## 三、状态机总览

```
[质检完成] ──(用户接受+核销)──→ [待上架申请] ──(运营审核)──→ [在库可售]
                                                                    │
                                                               (用户下单)
                                                                    ↓
                                                               [付款中]
                                                                    │
                                                    ┌─(支付成功)──→ [已售]
                                                    │                │
                                                    │           (仓库出库)
                                                    │                ↓
                                                    │           [已发货]
                                                    │
                                                    └─(超时)──→ [在库可售]

```
终端状态：[已完成-拒收]（外观拒收）、[已发货]（售出完成）
