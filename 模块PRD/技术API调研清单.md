## 一、IMEI 与设备合规

### 1.1 IMEI 黑名单 / 报失 / 被盗查询

| 项目 | 说明 |
|------|------|
| **关联功能** | CLOUD-P0-01 §3.3.2.0 准入检查 |
| **调研优先级** | P0（MVP 核心准入逻辑） |
| **调研问题** | ① 印度 DoT CEIR 系统是否有公开 API？接入流程和认证方式是什么？② 是否有第三方聚合服务商（如 GSMA Device Registry）提供统一接口？③ API 返回的数据字段有哪些（是否含运营商锁、报失时间、报失来源）？④ 单次查询成本和批量查询限制？ |

**候选调研方向：**

| 候选 | 说明 |
|------|------|
| 印度 DoT CEIR (Central Equipment Identity Register) | 官方系统，接入需向 DoT 申请，API 可用性待确认 |
| GSMA Device Registry / IMEI DB | 全球运营商共享的黑名单库，接入需成为 GSMA 会员 |
| 第三方 IMEI 查询服务 | 如 IMEI.info、IMEI24 等第三方 API（需评估数据准确性和法律合规性） |

### 1.2 激活锁 / iCloud / FRP 状态检测

| 项目 | 说明 |
|------|------|
| **关联功能** | CLOUD-P0-01 §3.3.2.0 准入检查 |
| **调研优先级** | P0 |
| **调研问题** | ① Apple 是否有官方 API 可查询 iCloud 锁状态（目前无公开 API，需通过间接方式）？② 对于 Android 设备，FRP 状态的检测是否可以完全由平板端 ADB 命令覆盖？③ 是否需要对接第三方激活锁检测服务？ |

**候选调研方向：**

| 候选 | 说明 |
|------|------|
| 平板端 ADB/USB 检测 | Android 设备通过 ADB 查询 FRP 状态；iOS 设备通过 libimobiledevice 查询激活锁状态——这是本地检测，非 API |
| Apple GSX (Global Service Exchange) | Apple 授权服务商的设备查询系统，需与 Apple 签约 |
| 第三方激活锁检测 API | 如 iUnlocker、IMEICheck 等（需评估可靠性和合规性） |

### 1.3 设备分期/EMI/贷款状态查询

| 项目 | 说明 |
|------|------|
| **关联功能** | CLOUD-P0-01 §3.3.2.0 准入检查（需求 5 缺口） |
| **调研优先级** | P1 |
| **调研问题** | ① 印度主要 NBFC（Bajaj Finance、HDB Financial、TVS Credit、Mahindra Finance 等）是否提供 IMEI 级别的贷款状态查询 API？② 如果没有统一 API，是否有第三方聚合平台提供此类查询？③ 如无可用 API，可否以用户自行申报 + 法律免责声明作为过渡方案？ |

### 1.4 IMEI TAC 码设备信息识别

| 项目 | 说明 |
|------|------|
| **关联功能** | APP-P0-03 商城浏览（参数规格 Tab）；核销环节新手机自动识别 |
| **调研优先级** | P0（商城参数展示依赖此数据） |
| **调研问题** | ① 是否有公开的 TAC（Type Allocation Code，IMEI 前 8 位）→ 品牌/型号/规格的映射数据库？② 如 TAC 数据库覆盖不全，品牌/型号是否需要人工维护？③ 是自建 TAC 库还是对接第三方 API（如 GSMA TAC Database）？ |

**候选调研方向：**

| 候选 | 说明 |
|------|------|
| GSMA TAC Database | 全球授权设备 TAC 分配表，可查到品牌和型号，但无详细规格 |
| 第三方设备信息 API | 如 DeviceAtlas、51Degrees 等设备检测服务 |
| 自建 TAC-型号映射表 | 运营后台手动维护常用品牌/型号对应关系，P2 自动化 |

## 调研阻塞项风险评估

| 风险项 | 如果 API 不可用/不成熟 | 降级方案 |
|--------|------|------|
| IMEI 黑名单 API | DoT CEIR 可能无公开 API | ① 接入第三方 IMEI 查询服务；② 最低方案：仅本地黑名单库（手动维护报失列表） |
| iOS 检测 | libimobiledevice 在 Android 上交叉编译困难 | ① iOS 设备仅做目视外观检测 + Apple 系统内电池健康截图；② 仓库端用 Mac + Apple Configurator 补充检测 |
| Razorpay | 成熟服务，风险最低 | — |
| 激活锁检测 | Apple GSX 需签约 | iPad 端通过 USB 读取激活锁状态（本地检测，非 API） |
